# Sécurité

## Signaler une faille

**N'ouvre pas d'issue publique pour une faille de sécurité.**

Utilise le signalement privé de GitHub : onglet **Security** du dépôt > **Report a vulnerability**. Décris ce que tu as trouvé, comment le reproduire et l'impact possible.

Tu recevras une réponse dès que possible. Merci de laisser un délai raisonnable pour corriger avant toute divulgation publique.

## Périmètre

Le site est statique et ne collecte aucune donnée personnelle. Les points sensibles sont : l'injection de contenu dans les pages, les dépendances npm, la configuration de sécurité des pages (CSP) et, plus tard, les comptes et l'API.
